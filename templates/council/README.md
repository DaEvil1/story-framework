# Council of Readers

Target-audience members who answer: "was this written for me?"

## Members
Define 4-6 audience archetypes BEFORE reading verdicts.
Each measures a different dimension of reach.

## Protocol
Each member returns:
1. Score 1-10 (their reading experience)
2. "This book is about ___" (communication check)
3. Favorite moment
4. Where they drifted
5. Would recommend, to whom?

Scores tracked in tests/reception_scores.yaml.
Divergence between members is a finding, not noise.

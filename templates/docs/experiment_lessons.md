**EPISTEMIC STATUS:** All entries are PROVISIONAL HYPOTHESES derived from a
small number of manuscripts. They describe patterns observed so far, not
universal laws. Each carries a confidence level and would be falsified by
counter-evidence. Do not treat as commandments. When an observation starts
sounding like an aesthetic absolute ("the best X is always Y"), rewrite it
as a hypothesis with falsification conditions.

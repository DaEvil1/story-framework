# Character Board Protocol v2

## Two modes (do not conflate):

### Continuity / Veto
Information: everything the character has experienced UP TO THAT POINT.
Question: "What do you do now? What feels impossible?"
Authority: OBJECTIONS trigger experiments (`exp/veto/...`), not prose fixes.

### Retrospective Arc Witness
Information: complete book, no intent docs or rubric scores.
Question: "Where were you flattened, used by plot, absent, or surprisingly right?"
Authority: ADVISORY. Findings feed editorial board discussion.

## World-experience reservoir
NOT a gap-detector. Classify lived-world details as:
AVAILABLE (true, no reason to appear) | RELEVANT (use if scene touches it) | GAP (absence makes scene false)

Most entries should be AVAILABLE. Unseen knowledge subtly affects writing.

## Weight system
| Type | Authority |
|---|---|
| OBJECTION | Experiment trigger (mandatory PROBE or documented refusal) |
| GAP | Editorial board item (discussion, not insertion mandate) |
| CONFIRMATION | Recorded for stability |
| NOTE | Advisory |

## Creative pulse ordering
The pulse happens BEFORE reading any character board output.
Instinct requires comparatively uncontaminated input.
